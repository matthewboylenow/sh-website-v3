Small 3.0 adjustments I've future-proofed

  • Rust contrast: inline text links use --sh-rust-dark (#A73F25) by default — it clears AA on white where the base rust (4.2:1) just misses. Base rust still used for buttons and icons where contrast isn't tested against body text.
  • Density token: new --density-scale multiplies section padding. Lets editors tune rhythm per surface without touching components.
  • Mobile Give FAB: floating give button appears on long pages below 760px — honors the "Stronger Give presence" tone note without cluttering desktop.
  • Placeholder-friendly: every hero, photo card, and video tile renders a clear "photo/video placeholder" state so the site works before real assets land — and degrades gracefully if any piece is missing.
